🌿 Exportar HTML a Figma — sin PNG

Captura cada pantalla real ya renderizada (con productos, imágenes y botones), embebe style.css e imágenes en base64, y copia un documento HTML completo al portapapeles. Sin generar ningún PNG.

Sesión de prueba (para que el Panel exporte con datos)

¿Cómo llevarlo a Figma?

1. Instala en Figma el plugin HTML to Figma (Community) o html.to.design.
2. Pulsa Copiar HTML en cada pantalla (o Copiar TODAS para las 3 en un solo documento).
3. En Figma abre el plugin y pega el HTML copiado. Los productos ya vienen renderizados y las imágenes van embebidas (base64), así que se verán sin depender de localhost.
Nota sobre los botones: el plugin HTML to Figma convierte el HTML en capas estáticas y editables; JavaScript no se ejecuta dentro de Figma, por eso los botones se ven pero no se pueden "pulsar". Eso es una limitación del plugin, no del archivo exportado. Todos los botones, tablas y textos quedan como capas editables.
